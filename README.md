# Fred — Internet Troubleshooting Prototype

An interactive design concept by Ish Singh for the Divami Design Assignment.

## View locally

Open `index.html` in a browser. Everything is included in this file; no installation or build is required.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `.nojekyll`, and this `README.md` directly to the repository root. Do not place them inside another folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/ (root)**, then click **Save**.
6. When deployment finishes, GitHub will display the published site link on the Pages settings screen.

## About the prototype

Six selectable states demonstrate a healthy connection, a detected issue, node details, a conversation with Fred, billing, and support. Diagnostic checks, account information, and assistant responses are illustrative and scripted. No live diagnostic, payment, remote restart, or support request is performed.

The presentation PDF is separate from this website.
